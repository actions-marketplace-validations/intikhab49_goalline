goalline / Benchmark

Replaying 200 merged pull requests of pallets/click

goalline history ran goalpost on the last 200 merged pull requests of pallets/click. 84 edited an existing test. 63 of those kept every old test passing, and 19 moved an expectation, each shown with its old and new values. It took about 2 minutes of machine time.

Each PR was judged on its merge commit against its first parent, with pytest 9.0.2 on Python 3.11, for the merged PRs up to 2026-10-04.

A flag is not a bug report

click's maintainers changed behaviour on purpose and updated the tests to match. In #3239, a --flag option with prompt=True, default=True, flag_value=False went from Flag [y/N]: (Enter gives False) to Flag [Y/n]: (Enter gives True), with three lines of a test table edited to match and all 11 CI checks green. That is the point: a reviewer sees the change and its values, not just a green check.

Judged as first opened as well (--first-heads, 199 PRs), no PR edited a test to hide a change that review then took back.

Reproduce it

Clone click, install it and pytest into a virtualenv, activate it, and run:

npx github:intikhab49/goalline history --from-git --limit 200 -- python -m pytest {files}

Run it on your repository

npx github:intikhab49/goalline history --from-git -- npx jest {files}

It writes goalline-history/report.md: the PRs that need a look, with the old and new values, next to the number a 'test file changed' alarm would fire on. It runs one check at a time while the machine is idle, and resumes where it stopped.
